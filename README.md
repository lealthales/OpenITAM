# OpenITAM
Desenvolver uma plataforma corporativa capaz de realizar o inventario automatizado dos ativos de TI, permitindo identificar computadores, usuários, componentes de hardware, softwares instalados, informação do sistema operacional e demais dados relevantes para administrar o ambiente

Solicitado pelo gestor para ampliar o conhecimento da equipe, fui orientado e auxiliar do analista da area
